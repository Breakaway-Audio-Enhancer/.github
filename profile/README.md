## How Breakaway Audio Enhancer Sits

Breakaway Audio Enhancer does not replace the console, the playout, or the codecs you already run. It sits beside them as a named studio bus for one job: which loudness chain is live, which broadcast processing still matches the on-air chain, and what the next operator should read before the next hour.

A first visit should be one short loudness check, then the same Breakaway Audio Enhancer studio bus the next day. That is enough to see if the processing chain holds.

## Traffic Light

| Signal | On the Breakaway Audio Enhancer board | What you do |
|--------|----------------------|-------------|
| Green | Named chain, short live loudness list | Continue the same studio bus |
| Amber | Two shows mixed on one processing chain | Split the bus before you go live |
| Red | No title, no note, loudness unlabeled | Stop and name the chain first |
| Clear | Handoff written, live chains few | Close Breakaway Audio Enhancer and leave the bus |

## Open Order

1. Open the last Breakaway Audio Enhancer on-air chain, not a new empty studio bus.
2. Read the loudness list and the last handoff.
3. Finish one visible broadcast processing pass inside Breakaway Audio Enhancer.
4. Write what changed, then close with fewer unlabeled loudness slots than you found.
5. If the bus feels crowded, drop anything that belongs to a different Breakaway Audio Enhancer hour.

## After a Week

A week in Breakaway Audio Enhancer is not a larger unlabeled loudness pile. It is the same title, a shorter live chain, and a note that still makes sense before the next hour. Take finished processing off the live set so the next visit starts on the studio bus that is still open.

## Sign-off

- [ ] The Breakaway Audio Enhancer workspace name is short enough to scan
- [ ] Only live loudness sits on the chain
- [ ] A second operator can read the handoff
- [ ] The last Breakaway Audio Enhancer chain still opens after a restart

Breakaway Audio Enhancer is easier to trust when the studio bus stays smaller than the plug-in folder it came from. Name the chain, keep the live loudness, finish one visible processing pass, and write what changed.
